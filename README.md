# ♟️ Lichess Chess Analytics — Streamlit app

## تشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```
حط `games.csv` (من Kaggle: datasnaek/chess) أو `clean_data.csv` من النوتبوك جنب `app.py`، أو ارفعه من الشريط الجانبي.
